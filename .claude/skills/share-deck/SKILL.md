# share-deck

발표 주제를 받아 슬라이드 HTML 여러 장을 만들고, 한 장씩 넘기는 발표 페이지 `index.html`로 묶는다.

## 절차

1. **도구 준비:** 이 스킬 폴더(`${CLAUDE_SKILL_DIR}`)의 `build.js`와 `vendor/qrcode.js`를 작업 폴더로 복사한다. 이미 있으면 그대로 쓴다.
2. **설정 쓰기:** `deck.config.json`에 `title`·`subtitle`·`presenter`·`date`를 적는다. 모르는 값은 `○○○`로 둔다.
3. **슬라이드 쓰기:** `slides/01-표지.html`처럼 만든다. 아래 규칙을 따르고, 따로 정하지 않았으면 5장으로 한다.
4. **묶기:** `node build.js`를 실행하고 출력된 장 수와 제목을 확인한다.
5. **(사람) 브라우저로 확인:** 여기서 멈추고 아래 "보고" 내용을 전한 뒤, 사용자가 확인해 줄 때까지 기다린다. 사용자가 원할 때만 `Start-Process index.html`로 열어 준다.

슬라이드만 고친 뒤 "다시 묶어 줘"라고 하면 4번부터 한다.

## 슬라이드 규칙

| 규칙 | 이유 |
|---|---|
| 파일 이름은 두 자리 번호로 시작한다(`02-이름.html`) | 이 형식의 파일만 번호 순으로 묶인다 |
| 한 파일이 완결된 HTML이고, CSS는 파일 안에 넣는다 | 각 장이 따로 떨어진 iframe에 들어간다 |
| `html, body` 크기를 1280×720으로 고정한다 | 발표 페이지가 이 크기를 화면에 맞춘다 |
| `<title>`에 슬라이드 제목을 쓴다 | [목차]에 그대로 나온다 |
| 설정값은 `{{title}}` `{{presenter}}`처럼 쓴다 | 묶을 때 config 값으로 바뀐다 |
| 링크나 버튼을 넣지 않는다 | 화살표 키가 먹히도록 슬라이드 클릭을 막아 두었다 |
| 외부 이미지나 폰트 대신 이모지를 쓴다 | 인터넷이 없는 교실에서도 열려야 한다 |

- 스타일 예시: `templates/cover-slide.html`(표지), `templates/content-slide.html`(본문)
- 내용은 듣는 사람에게 맞는 쉬운 말로 쓰고, 출처 없는 수치는 넣지 않는다.
- `index.html`은 직접 고치지 않는다. 발표 페이지 기능을 바꿀 때는 `build.js`를 고친다.

## 보고 (5단계에서 멈출 때)

- 만든 파일과 슬라이드 제목 목록
- 확인할 것: ← → 넘기기, [목차], [QR], [전체화면](F 키), Esc로 창 닫기
- 고치는 법: 슬라이드나 `deck.config.json`을 고친 뒤 `node build.js`
- 남은 `○○○` 값이 있으면 채워 달라는 부탁
- **QR 주의:** 파일로 열면 주소가 `file:///…`이라 휴대폰에서 열리지 않는다. 공유하려면 `index.html`과 `vendor/`를 GitHub Pages 같은 곳에 올린 뒤, 그 주소에서 QR을 띄워야 한다.
